1. Your free YouTube API key

Each person uses their own free key, so nobody shares limits. It is saved on this device only.

How to get a free key (about 10 minutes)
  1. Go to console.cloud.google.com and sign in. Create a project, name it anything.
  2. Open APIs & Services, then Library. Search "YouTube Data API v3" and click Enable.
  3. Open Credentials, then Create credentials, then API key. Copy it.
  4. Click the key, under API restrictions choose YouTube Data API v3 only, and save.
  5. Paste the key above and press Save key. Never post it publicly.
